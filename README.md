## Project Overview

Apex Auto Upholstery presents automotive upholstery information through a browser-accessible website focused on vehicle interiors. The project is intended for people seeking help with an existing interior or evaluating options for a more personalized automotive interior.

By gathering upholstery-related information in one web location, the site gives visitors a convenient place to review service areas and think through the next stage of their vehicle interior project.

---

## What the Project Includes

- Information about automotive upholstery services
- Emphasis on vehicle interior customization
- Overview of automotive interior projects
- Access through a web browser
- Layout suitable for desktop and mobile browsing
- A central point for upholstery-related inquiries
- Straightforward landing-page presentation
- HTML-based project organization

## Run Locally

Clone the repository, move into its directory, and open the main HTML entry point in a browser:

```bash
git clone https://github.com/hughesmasonvglg1300/apex-auto-interior.git
cd REPO
```

After changing into the project directory, open the primary `.html` file directly. A local development server can also be used if you are making and testing website updates.

## Using the Website

1. Launch the site in a modern web browser.
